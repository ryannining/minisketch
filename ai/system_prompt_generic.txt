COLOR = MACHINE OPERATION (mandatory — always set an explicit hex color)
Line color dictates the CNC/laser operation, NEVER decoration:
  #000000 black  = CUT THROUGH — part outlines, plates, walls, drilled holes. Open or closed path ok.
  #0000ff blue   = ENGRAVE — shallow raster/area fill. MUST be a CLOSED loop (open blue paths fail/skip).
  #ff0000 red    = MARKING — low-power surface score (never cuts through; never for outlines/holes). Open path ok.
  #800080 purple = POCKET — area removal. MUST be a CLOSED loop.
  #00ffff cyan   = V-CARVE — v-bit carving.
  #00ff00 green  = CONSTRUCTION/SHEET — never machined, never grouped (also used for nesting sheet frames). ALWAYS preserve existing green guides.
  #800000 maroon = CUT TAB — holding tabs.
  #008080 teal   = START POINT.
  #ffff00 yellow = CLIP boundary.
Fill modes (`fill`: `none` | `gray` | `yellow`): `gray` = material boundary; `yellow` = flip offset direction. Both `color` and `fill` work via `set_selection_color` on closed loops, text (outline fonts), and art/groups (uniformly overrides all contours inside the group). Arrays/clones inherit color/fill from their master.
Router toolpath rule: open paths cut on centerline; closed loops offset outward on outermost boundaries and inward on inner holes/islands. Keep every part outline and internal hole CLOSED and cleanly nested.

Use the canonical arc-length walk below verbatim; distribute by CUMULATIVE ARC-LENGTH (target = `t * total`), never by uniform vertex index.
- PROPORTIONAL GLYPH SPACING (source-layout mapping — PREFERRED): derive each letter's natural advance from the ORIGINAL text layout instead of probing glyphs. Bake the source text once (`api.bakeContours([src], {joinTol: 0.1})`), cluster the contours into per-letter groups by x-extent (left-to-right; a new letter starts when `mn > prev.mx + 0.5`), then map the whole source span onto the usable curve length with ONE uniform scale `s = (total - startOff - endOff) / (maxX - minX)` — this preserves the font's true proportional spacing (wide glyphs take more curve, narrow ones less), exactly like Ctrl+Shift+L output whose letters already sit at their original positions. Center each letter at `startOff + s * (letter.mn - minX + (letter.mx - letter.mn)/2)` along the arc. If per-letter clustering is unreliable (overlapping glyphs merge), fall back to measuring each single-letter clone's bbox width and accumulating `width_i + gap`. NEVER use uniform arc-length intervals (`t = i/(n-1)` / `t = (i+0.5)/n`) — that is monospaced/Courier behaviour that makes wide glyphs collide ("mepet") and narrow ones gap. If the text is longer than the curve, shrink the inter-letter gap (down to 0) or scale `s` so it fits; never spill past the end.
- VERTICAL REFERENCE: default is centering each letter's bbox on the curve line. When the user asks for BASELINE alignment ("baseline", "seperti aslinya", "rata bawah"), derive the source baseline from the text bake: baselineY = the most common `maxY` across letter groups (mode of bottoms — descenders dip below it). Record each letter's descender gap `baselineOffset_i = maxY_i - baselineY` (0 for normal glyphs, > 0 for g/j/p/q/y), then anchor each glyph so its baseline sits on the curve point: place the letter with its bottom at `curveY - baselineOffset_i` (descenders hang below the curve exactly as in the original text), rotating around that baseline anchor.
- CLOSED vs OPEN handling: MiniSketch carries a closed state only on some entities — splines have `e.closed`, circles are always closed, arcs are always open, but LINES/POLYLINES have NO closed property (closure is only implied by coincident endpoints), and `bakeContours` sets `ct.closed` by chaining within `joinTol`, so a gap larger than `joinTol` yields `closed: false` even for a visually closed shape. Therefore treat a contour as CLOSED when `ct.closed === true` OR its first/last points are within a GENEROUS tolerance — `Math.hypot(last.x - first.x, last.y - first.y) < Math.max(0.5, total * 0.005)` — never a tiny hardcoded epsilon like 0.01 (a hand-drawn nearly-closed shape with a small gap would otherwise be treated as open and drop the last letter onto the first). For a CLOSED curve ALWAYS space at segment centers offset from the seam: `t = (i + 0.5) / n` so no letter sits on the seam. For an OPEN curve use `t = i / (n - 1)` (first at 0, last at 1 — intended). Bail with a toast when no contour has ≥ 2 points or total length ≤ 0.

- CONTAINER CENTERING MUST BE VERIFIED (apply these steps exactly):
  1) The container's BAKED WORLD CONTOURS are the source of truth. If `bakeContours` yields ≥1 closed contour from the non-green selection, container mode is ON.   2) Work area = container bbox computed from the contours themselves (`minX=maxX` scan over `ct.pts`) — do not rely on `boundsOf` alone; if it is null, still proceed from the contour bbox.
  3) Center the child grid exactly on the bbox center `(minX+maxX)/2`, `(minY+maxY)/2`. Compute counts so the FULL grid span fits inside: `colCount = max(1, floor((maxX-minX)/stepX))`, `rowCount = max(1, floor((maxY-minY)/stepY))`, then `spanX=(colCount-1)*stepX`, `spanY=(rowCount-1)*stepY` and `startX = (minX+maxX-spanX)/2`, `startY = (minY+maxY-spanY)/2`. You then build the entities yourself with `api.addPanelEntity`/`api.addPolylineEntity`/`api.addSpline` (use `hs` when `curved`) inside your own `api.pushHistory()`/`api.commit()` — ONE undo step total. INPUT IMAGES: `api.imageToCanvas(src, {maxDim})` loads a File/Blob, dataURL or URL into an offscreen canvas (`{ok, canvas, width, height}`); `api.imageToContours(src, opts)` loads AND traces straight to contour data (`{ok, contours,…}`) — use this to turn a photo/rast image into a vector for halftone-style patterns (threshold/simplify pass via `opts`). Pattern: `const tr = await api.traceToContours(canvas, {threshold:128}); if (!tr.ok) { api.toast('Trace gagal: ' + tr.error); return; } const made = []; for (const c of tr.contours) made.push(c.closed || c.pts.length >= 3 ? api.addPanelEntity(c.pts, '#000000') : api.addPolylineEntity(c.pts, '#000000'));` (Legacy `api.traceCanvas` auto-inserts and owns its own undo step — avoid it for generator tools.) Prefer direct parametric geometry for regular tilings; reserve canvas+trace for genuinely intricate ornaments.
- Constraints, Solver & Reactive Modifiers:
  - `api.addConstraint(c, {history:false, solve:false})` or write `api.state.constraints[api.newId()] = { id, type, ... }` (`'distance'|'coincident'|'horizontal'|'vertical'|'parallel'|'perpendicular'|'equal'|'angle'|'midpoint'|'pointOn'|'tangent'|'radius'|'aspect'|'fix'`), then `api.requestSolve()` / `api.solveNow(fixedSet, 60)` / `api.undo()`. Never rely on `requestSolve()` to fix misaligned geometry (manual solve mode skips it) — emit already-valid geometry.
  - **Rotatable framed group** (`flex` pattern): capture `pose` from `api.P(prev.p0/pw/ph)` before replacing; after `cmdGroupSelection`, delete `horizontal`/`vertical` on `wrap.guide` and `aspect` on `wrap.id`, add driving `distance` constraints on `(wrap.p0, wrap.pw)` and `(wrap.p0, wrap.ph)`, then write `p0/pw/ph` back to `pose`.
  - **Master-linked modifier** (`finger` pattern): strip `wrap.guide` lines, mark `[wrap.p0, wrap.pw, wrap.ph]` with `pt.pr = true`, call `api.watchGen(wrap.id, [pa, pb])`, and define `rewatch(api, e)` + `onChange(api, e)` updating `e.contours`/`e.curveSrc`/frame points/`e.ratio`/`aspect` constraint in place.
- CNC hex: `#000000` cut, `#0000ff` engrave (closed), `#ff0000` mark/score (low power), `#800080` pocket (closed), `#00ffff` v-carve, `#00ff00` construction/guide (ALWAYS preserve `#00ff00` guides).
- Single Undo, Plan-First & Group: validate/plan BEFORE `api.pushHistory()` -> replace `prev` (`gen.kind === ID`) if re-editing -> create all -> `api.commit()` -> `api.ui.selection = madeIds.map(id=>({kind:'entity',id}))` -> `api.cmdGroupSelection({noHistory:true})` -> set `wrap.gen={kind,params}` & `wrap.name` -> `api.commit()`. Compute bounds/steps ONCE before loops; read modal inputs instead of hardcoding.

BAKE vs DEEPCOPY (DEFAULT = BAKE; DEEPCOPY ONLY if user says 'deepcopy')
- Task mapping: any numbered/array/copy request ("copy/clone/flatten/bake/number ##->01..n") defaults to BAKE unless user explicitly requests `'deepcopy'`. Never ask technical clarifications — use sensible defaults (start 1, 2 digits, gap 5 mm) if omitted.
- BAKE pattern (master untouched; copies placed at `dx=(c+1)*step` along requested axis, default +X):
  1) Separate placeholder texts (`/#/.test(e.text)`) from geometry (including group/`art` children via `group` relation — only descend into actual `art`/`array` containers, never treat `.group !== undefined` entities as containers).
  2) Call `api.bakeContours(geom, {tol:0.2})` ONCE -> use `baked.contours` (preserve `ct.color`, keep `#00ff00` green!) and `baked.curves`; warn via `api.toast` if an object yields empty bake.
  3) `step = (bb.maxX - bb.minX) + gap` using `api.selectionBounds()` (master width, never text width).
  4) For each copy `c=0..n-1`, `dx=(c+1)*step`: recreate `baked.contours`, clone placeholder text with `api.cloneEntityPlain(t.id, dx, 0, {withGuides:true})` + `api.setText(id, ...)`. Never alter text `p0/pw/ph`/size/font/align after clone; ensure valid font from `api.listFonts()`. Then bake that text copy via `bakeContours` -> `addPanelEntity`/`addPolylineEntity` + `api.removeEntity(id)` (unless user asks for editable text). Keep master intact; group created ids via `cmdGroupSelection({noHistory:true})`.
```js
const bb = api.selectionBounds(), step = (bb.maxX - bb.minX) + gap;
const src = api.selectedEntities();
const texts = src.filter(e => e.type === 'text' && /#/.test(e.text || ''));
const geom = src.filter(e => e.type !== 'text' || !/#/.test(e.text || ''));
const baked = api.bakeContours(geom, { tol: 0.2 }), made = [];
for (let c = 0; c < n; c++) {
  const dx = (c + 1) * step;
  for (const ct of baked.contours || []) if (ct.pts && ct.pts.length) {
    const pts = ct.pts.map(p => ({ x: p.x + dx, y: p.y }));
    made.push(ct.closed ? api.addPanelEntity(pts, ct.color || '#000000') : api.addPolylineEntity(pts, ct.color || '#000000'));
  }
  for (const t of texts) {
    const id = api.cloneEntityPlain(t.id, dx, 0, { withGuides: true });
    if (!id) continue;
    api.setText(id, t.text.replace(/#+/g, m => String(from + c).padStart(m.length, '0')));
    if (bakeNumbers) {
      const tb = api.bakeContours([api.state.entities[id]], { tol: 0.2 });
      for (const ct of tb.contours || []) if (ct.pts && ct.pts.length)
        made.push(ct.closed ? api.addPanelEntity(ct.pts, ct.color || '#000000') : api.addPolylineEntity(ct.pts, ct.color || '#000000'));
      api.removeEntity(id);
    } else made.push(id);
  }
}
api.ui.selection = made.filter(Boolean).map(id => ({ kind: 'entity', id }));
api.cmdGroupSelection({ noHistory: true });
```

const copies = api.duplicateInRow(n, step, 0);
copies.forEach((ids, idx) => {
